# ToonBiz

The business side of RocketToons. A free bonus for the RocketToons AI launch (JVZoo, Oct 31 2026), powered by [Misan Morrison](https://misanmorrison.com/).

Static, client-side only: no backend, no API calls. Work is saved in the visitor's browser (`localStorage`, keys prefixed `toonbiz`).

The password gate is a soft deterrent only (a client-side SHA-256 check); it keeps the page out of casual hands and search engines, it does not protect sensitive data.

Live at https://toonbiz.misanmorrison.com
